1. FIX THE CROP PERSISTENCE BUG

Current failure:

* I select an aspect ratio.
* I reposition and zoom the image so the face is visible.
* The cropper looks correct.
* After I tap Done/Apply and return to Compose Edit, the image is cropped again from the center and the face disappears.
* The published image may also use a different crop.

Required implementation:

* Save the exact crop state for every image:
    * aspect ratio
    * crop X position
    * crop Y position
    * zoom/scale
    * rotation if supported
* Tapping Done in the crop editor must immediately commit the crop and update the Compose Edit preview.
* Do not require a second "Save this Edit to keep the new image" step.
* Use the same saved crop data and the same image renderer in:
    * crop editor
    * Compose Edit preview
    * Home feed
    * creator profile grid
    * Edit detail page
    * published post
* Do not fall back to object-fit: cover with object-position: center after leaving the cropper.
* Saving a draft, refreshing the page, reopening the Edit and publishing it must preserve exactly the same crop.
* The Compose Edit preview must match the final published result pixel-for-pixel.

1. Upload a vertical full-body portrait.
